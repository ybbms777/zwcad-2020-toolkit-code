# ZWCAD 2020 整合工具包 1.2

中望 CAD 2020 中文版（Windows）插件整合包，含常用缺失字体补齐。

一次安装，之后每次打开 CAD 或图纸自动加载。

## 功能

| 命令 | 功能 |
|---|---|
| `ZD` 系列 | 智能标注：点选标注点/对象，仿 AutoCAD 快速标尺寸 |
| `TR` | 快速修剪：划过多余线段松开即剪 |
| `EX` | 快速延伸：延伸与修剪一键切换（Shift 拖动修剪） |
| `GC` | 几何公差：调用原生公差对话框快速放置 |
| `FH` | 机械符号：沉孔·深度·直径·沉头，ZGDT 符号字体 |
| `ZF` / `ZFD` | 改字体：宋体·华文细黑·Arial + 字高 + 颜色，支持批量框选 |
| `BZ` / `BZD` | 标注线属性：标注线/箭头颜色·大小·线宽，支持批量框选 |
| `FE` | 栏选删除 |

7 个模块可独立勾选安装，`TR`/`EX`/`FE` 为基础组件始终加载。

## 安装

双击 `一键安装.cmd`：

- 选 `1`-`8`（或 `8` 全部安装）：安装插件，同时把 `fonts\` 全部字体装进系统
- 选 `9` 字体安装：单独装字体，可多选
- 选 `0` 退出

安装后重启 CAD 生效。卸载/取消自动加载：双击 `取消自动加载.cmd`。

## 更新（云更新）

双击 **`更新.cmd`**。它会从公开代码仓库拉取版本清单，**只下载发生变化的文件**：

- 代码部分只有 ~130 KB，一次典型更新通常 1-3 个文件、几十 KB
- `fonts\`（112 MB）不参与更新
- `selection.lsp`（你自己的模块勾选）不会被覆盖
- 更新前自动备份到 `_backup\日期时间\`
- 目标机器**不需要安装 git**

## 发布（给作者自己用）

改完代码后双击 **`发布.cmd`**：

1. 重算全部代码文件的 sha256 → 生成 `version.json`
2. 同步代码到公开仓库工作目录（`C:\Users\Administrator\zwcad-toolkit-publish`）
3. 提交并推送：公开仓库（更新源）+ 私有仓库（含字体全量备份）

版本号默认自动 +1，也可 `发布.cmd -Version 1.3` 指定。

> 为什么分两个仓库：`fonts\` 里的字体是第三方商业字体，不能进公开仓库；
> 公开仓库只放代码（~130 KB），负责当更新源；私有仓库保留完整包做备份。

## 目录结构

```
boot.lsp            选择性加载入口（zwk:modkeys 查表）
modules.lsp         模块加载清单
selection.lsp       当前启用的模块
install.ps1         实际安装逻辑（写 zwcad.lsp 钩子 + 字体）
cli.ps1             交互式菜单
update.ps1          云更新器（只下变化的文件）
publish.ps1         发布器（生成 version.json + 推两个仓库）
version.json        版本 + 文件指纹清单（更新源用）
modules\            各功能模块 lsp
fonts\              字体文件 + 字体说明.txt
src\                DLL 源码（C#）
bin\                编译好的 ZWKit.Core.102.dll
```

## 关于字体

`fonts\` 里的字体用于补齐图纸引用的缺失字体，安装时会：

- `.ttf` / `.ttc` / `.otf` → 复制到系统字体库并写注册表
- `.shx` → 复制到 ZWCAD 的 `Fonts` 目录

**注意：这些字体均为第三方商业字体**（中易、华文、方正、Autodesk 等），
仅作本机图纸显示用途，**请勿公开传播**。

常见缺失字体对应关系：

| 提示 | 字体 | 说明 |
|---|---|---|
| 未找到字体: bigfont | `bigfont.shx` | 日文大字库（码页 1） |
| 未找到字体（中文老图纸） | `chineset.shx` / `gbcbig.shx` | 中文大字库 |
| 中文显示成 `?` | `STXIHEI.TTF` | 华文细黑，安装脚本会同时写字体映射 |
